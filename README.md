### 1. [技术报告（`NCUSCC_2026_技术报告.pdf`）](./NCUSCC_2026_技术报告.pdf)
共 62 页，介绍 Linux、Git、C/C++ 必修与可选任务的做法、关键实现和验证结果（17 项必修和 4 项可选，共 21 项；20 项通过自动检查，最后一项已收件、待人工审阅）：
- **Linux 基础与系统管理**：文件查找、最小字节修复、Shell 脚本参数与退出码控制、后台进程管理、服务账号权限隔离及构建日志排错。
- **Git 版本控制**：本地仓库初始化、工作区与暂存区状态核对、历史内容恢复、分支合并及可逆修改验证。
- **C/C++ 必修与可选任务**：单文件与多文件构建、边界与内存问题修复、调试测试结果及四线程快速排序观察。

### 2. [学习与感悟报告（`NCUSCC_2026_学习与感悟报告.pdf`）](./NCUSCC_2026_学习与感悟报告.pdf)
共 14 页，记录考核准备过程中的学习基础、解题困难、解决方式和心路历程：
- **起步与环境适应**：从图形界面转向命令行、筛选合适课程，以及区分本机、本地 WSL 与考核容器环境的过程。
- **解题困难与解决方式**：各模块遇到的卡点、尝试过程、求助与学习方式的调整及真实心理变化。
- **事后复盘与后续计划**：结合回看与追问梳理当前理解范围与后续学习安排。
